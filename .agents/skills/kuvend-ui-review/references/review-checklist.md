# Blocking review checklist

- Design: matches Mist × Notion language; compact sans hierarchy; no gradients, glass, cream, bento dashboard, decorative metrics, serif display, or pill clutter.
- System: apps import `@kuvend/ui`; no direct Base UI; no raw colors; no arbitrary type/spacing; no primitive overrides.
- Mobile: dedicated screens, 320px no overflow, 44px targets, sticky/safe actions, back navigation, one-thumb completion.
- Accessibility: semantic structure, visible focus, keyboard completion, names and labels, field errors, dialog title/description, axe serious/critical zero.
- States: loading, empty, error, disabled, long Albanian, reduced motion, 200% zoom, slow network.
- Product: final vote confirmation; split hidden before accepted vote; AI optional and side-by-side; structured evidence; recovery secret; no changed privacy boundary.
- Supply chain: Tailark dry-run provenance recorded; no demo assets or browser SDKs.
- Evidence: screenshots at required widths and passing test output attached to the change.
