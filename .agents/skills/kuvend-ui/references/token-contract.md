# Token contract

- Tokens live only in `packages/ui/src/styles.css` and are exposed through semantic `--kuvend-*` variables.
- Use canvas, ink, ink-soft, surface, border, primary red, focus, success, warning, and danger by meaning—not by visual preference.
- Use the spacing scale and 6/10/12px radii. Shadows are for overlays; normal cards are flat with a 1px border.
- Geist/system sans is the product typeface. Headings are compact, sans-serif, and never editorial display type.
- Dark tokens must remain complete, but migration work ships and verifies light mode only.
- Token changes require visual baseline review and CODEOWNERS approval.
